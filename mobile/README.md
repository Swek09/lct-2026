# «Питомец Финни» — Mobile Application 🐾

Детское мобильное приложение для формирования базовых финансовых навыков (Хакатон «Лидеры цифровой трансформации 2026», Задача №25 Департамента финансов Москвы).

Полная документация проекта, матрица ТЗ и руководство по сборке: [../README.md](../README.md).

## Быстрый запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Модульные тесты
npm test

# 3. Проверка типов и линтинг
npx tsc --noEmit
npm run lint

# 4. Запуск Expo Dev Server
npm start
```

## Архитектура клиента

- **3D-персонаж:** Риггированная авторская модель котика (`Cat.glb`) с контроллерами глаз/рта и 6 состояниями анимаций.
- **Движок 3D:** Three.js (WebGL) с процедурным ковриком, мягкими контактными тенями и адаптивным освещением.
- **Маршрутизация:** Expo Router (файловый роутинг в `src/app`).
- **Стейт-менеджер:** Zustand с персистентным хранением профиля в AsyncStorage.
- **Дизайн:** Чистая векторная и пастельная дизайн-система согласно ТЗ.
