# Мобильное приложение «Питомец Финни» 🐾

**Игровой сервис для формирования базовых финансовых навыков у детей 7–11 лет**  
*Разработано в рамках хакатона «Лидеры цифровой трансформации 2026» (Задача №25: Департамент финансов города Москвы)*

---

## 📌 1. Назначение продукта и концепция

«Питомец Финни» — это детское мобильное приложение в стилистике Duolingo с естественной цветовой палитрой (шалфей `#5E9362`, теплый лен `#FAF8F3`, тактильные 3D-кнопки), созданное на основе **Единой рамки компетенций в области финансовой грамотности**.

Приложение обучает ребенка 7–11 лет ключевым финансовым принципам через заботу о виртуальном друге:
1. **Ограниченность ресурсов:** за один период нельзя купить всё;
2. **Разделение трат:** обязательные расходы (еда, уход) vs желания (игрушки, наряды) vs сбережения;
3. **Планирование бюджета:** метод трех конвертов до начала периода и сравнение Плана с Фактом;
4. **Регулярные накопления:** постановка цели, пополнение копилки и защита от импульсивного снятия;
5. **Безопасная ошибка:** неудачный выбор не обнуляет прогресс, а дает обучающую подсказку Мудрой Совы и понятный путь восстановления.

## 🛠 3. Технологический стек и архитектура

- **Платформа:** React Native 0.76 / Expo SDK 52 (портретная ориентация, адаптивность под экраны от 360 dp)
- **Язык:** TypeScript (strict mode, 100% покрытие типов, 0 ошибок компилятора)
- **Управление состоянием:** Zustand + AsyncStorage (полное офлайн-сохранение)
- **Навигация:** Expo Router (File-based routing)
- **Звуковой движок и доступность (ТЗ 3.6):** Web Audio API синтезатор звуковых частот (монеты, клики, фанфары без внешних MP3) + тактильная виброотдача (Haptics), независимые тумблеры отключения звуков и анимаций
- **Интерактивные механики (ТЗ 2.5.8):** Корзины сортировки («Надо» vs «Хочу») и кассовый аппарат подсчета сдачи монетами
- **Единая рамка финансовых компетенций:** Интеграция стандартов `ФК-1` — `ФК-5` и столичного контекста (карта «Тройка», ВДНХ, Зарядье)
- **Стилизация:** StyleSheet с единой дизайн-системой (Duolingo 3D button depth, природный шалфей, теплый лен)
- **Тестирование:** Встроенный Node.js Test Runner + tsx (13/13 зелёных тестов доменной экономики, лимитов, периодов и достижений)

## 🚀 4. Быстрый запуск и пошаговая сборка

### Системные требования
- Node.js: `v18.0.0` или выше (рекомендуется `v22.x`)
- npm: `v9.x` или выше
- JDK: 17 (для локальной сборки Android APK)
- Android SDK: API Level 34

### 1. Установка зависимостей
```bash
cd mobile
npm install
```

### 2. Запуск тестов и линтера
```bash
npm test         # Запуск 13 модульных тестов доменной экономики
npm run lint     # Проверка ESLint (0 errors, 0 warnings)
npx tsc --noEmit # Проверка типов TypeScript (0 errors)
```

### 3. Локальный запуск в режиме разработки
```bash
npm start
# или
npx expo start
```
*Нажмите `a` в консоли для запуска на подключенном Android-устройстве или эмуляторе.*

### 4. Пошаговая инструкция по сборке релизного подписанного APK (ТЗ 3.3)
Сборка полностью автономна и не зависит от облачных сервисов Expo (EAS). Проект генерирует нативную платформу Android и компилирует подписанный APK с помощью Gradle.

#### А. Создание локального ключа подписи (Release Keystore)
Если у вас ещё нет ключа подписи для публикации:
```bash
keytool -genkeypair -v -storetype PKCS12 -keystore release.keystore -alias finni-release-key -keyalg RSA -keysize 2048 -validity 10000
```
*(Сам файл ключа и пароли не сохраняются в Git-репозитории в целях безопасности согласно ТЗ 3.4).*

#### Б. Настройка конфигурации подписи (Release Signing Config)
Параметры подписи передаются через файл `android/keystore.properties` (или переменные окружения CI/CD):
```properties
RELEASE_STORE_FILE=../release.keystore
RELEASE_STORE_PASSWORD=your_keystore_password
RELEASE_KEY_ALIAS=finni-release-key
RELEASE_KEY_PASSWORD=your_key_password
```
В файле `android/app/build.gradle` блок `signingConfigs.release` считывает указанную конфигурацию подписи (при отсутствии файла по умолчанию используется резервный debug-ключ для локальной проверки):
```groovy
signingConfigs {
    release {
        if (project.hasProperty('RELEASE_STORE_FILE')) {
            storeFile file(RELEASE_STORE_FILE)
            storePassword RELEASE_STORE_PASSWORD
            keyAlias RELEASE_KEY_ALIAS
            keyPassword RELEASE_KEY_PASSWORD
        } else {
            signingConfig signingConfigs.debug
        }
    }
}
```

#### В. Команды компиляции и проверки подписи
```bash
cd mobile
# Генерация нативного Android проекта
npx expo prebuild --platform android

# Сборка Release APK
cd android
./gradlew assembleRelease

# Проверка цифровой подписи APK (Android SDK build-tools apksigner)
apksigner verify --verbose app/build/outputs/apk/release/app-release.apk
```
*Собранный релизный файл будет находиться по пути:*  
`mobile/android/app/build/outputs/apk/release/app-release.apk`

## 🧪 6. Объем контента (ТЗ 2.6)

- **Питомцы:** 4 вида (Кот, Пёс, Кролик, Дракончик) × 4 цвета × 3 типа глаз × 3 наряда × 3 аксессуара = **432 комбинации** *(норма: ≥ 9)*.
- **Игровые периоды:** **5 последовательных периодов** в Демо-режиме без ожидания реального времени с автоматическим развитием питомца от Малыша до Взрослого *(норма: ≥ 5)*.
- **Задания:** **15 заданий** — ровно по 5 на каждую из 3 обязательных тем ТЗ:
  - **Планирование бюджета** (5 заданий): `income_sources`, `first_budget`, `mandatory_first`, `budget_compare`, `fixing_mistakes`;
  - **Сбережения и цели** (5 заданий): `savings_goal`, `savings_regular`, `impulse_vs_savings`, `unexpected_vet`, `level_up_financial`;
  - **Платежи и покупки** (5 заданий): `needs_vs_wants`, `envelope_method`, `check_change`, `discounts_trap`, `smart_comparison`.
  - Включают интерактивную механику перетаскивания/сортировки по корзинам («Надо» vs «Хочу») и кассовый аппарат для набора сдачи монетами.
- **Покупки:** **12 товаров** (6 обязательных: корм, вода, уход, лежанка, витамины, ветеринар; 6 необязательных: мячик, мишка, плащ, замок, мыльные пузыри, ролики) *(норма: ≥ 8)*.
- **Цели накопления:** **6 целей** от 55 до 450 монет *(норма: ≥ 3)*.
- **Награды и медали:** **8 наград** с коллекционной витриной медалей на главном экране.
- **Памятный сертификат:** Памятный игровой сертификат с фирменной печатью Финни, без официальной государственной символики, в родительском кабинете.
- **Стадии роста:** **3 стадии** (Малыш, Подросток, Взрослый) *(норма: ≥ 3)* с индикаторами настроения (✨ радость, 🥣 голод, 💤 сон).

## 🔒 8. Безопасность данных и разрешения Android (ТЗ 3.4, 3.5)

- **Полное отсутствие сбора персональных данных:** приложение не требует номера телефона, электронной почты, ФИО или даты рождения.
- **Разрешения Android:** в `app.json` указано `"permissions": []`. Приложение не запрашивает доступ к камере, микрофону, контактам, геолокации, Bluetooth или файловой системе пользователя.
- **Полная автономность:** основной игровой процесс работает без подключения к Интернету.
- **Удаление данных:** в разделе для родителей доступна кнопка одномоментного удаления всех данных профиля без обращения к разработчикам.

## 🎨 11. Графика, 3D-модели и лицензии (ТЗ 3.3, 3.4; Пояснения п. 11)

- **3D-модель персонажа:** Авторская 3D-модель питомца (`Cat.glb`), созданная и анимированная в Blender. Модель включает:
